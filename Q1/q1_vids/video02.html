How to Link CSS Stylesheet Using HTML

The lesson taught how to connect a CSS stylesheet to an HTML file. First, a CSS file is created inside VS Code. After creating the CSS file, a link tag is added to the HTML file to connect the two files.

Important Notes:

  • Create a CSS file inside VS Code.
  • Use the <link> tag to connect CSS to HTML.
  • The rel="stylesheet" attribute tells HTML that the linked file is a stylesheet.
  • The href="" attribute shows the location or name of the CSS file.
  • Linking CSS allows the HTML page to use the styles written in the CSS file.

Overall, the lesson taught the basic use of HTML and CSS and how to start creating a simple website.
