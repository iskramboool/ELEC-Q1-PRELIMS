How to Structure Your HTML

The lesson explained how to properly structure an HTML webpage. It discussed the use of different HTML elements, closing tags, and how elements can be placed inside other elements, similar to boxes inside boxes. It also explained semantics, which means using the correct HTML tags for their purpose.

Important Notes:

  • HTML uses different elements and tags to organize a webpage and the elements must have an opening tag and a closing tag. Those Elements can be placed inside other elements, like boxes within boxes.
  • Semantics means using tags or codes correctly based on their purpose. A Semantics is also important because it helps us use the correct tags for their purpose.
  • Code can be moved by selecting the text and using Shift + Left/Right.
  • A webpage can have different boxes or sections for the header, navigation, main content, footer, and other parts.
  • <header> – used for the header of the website.
  • <nav> – used for navigation or menus.
  • <main> – used for the main content of the webpage.
  • <section> – used for content that is related to a specific topic.
  • <article> – commonly used for blogs or separate pieces of content.
  • <aside> – used for side information or extra features.
  • <footer> – used for the bottom part of the webpage.
  • <div> – does not describe a specific type of content and is mostly used for organizing the structure.
  • <img src=""> – used to add an image.
  • <alt=""> – used to add a description for an image.
  • There are difference between using main tag and section tag; Main tags contains the main content of the webpage while section tags contain content that is related to a specific topic.

Overall, the lesson taught the basic use of HTML and CSS and how to start creating a simple website.
