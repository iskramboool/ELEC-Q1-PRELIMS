Add Styling to HTML Using CSS Selectors

The lesson focused on adding styles to HTML using CSS. CSS makes the website look better and allows us to change different parts of the webpage, such as colors and text. It also taught how to target specific HTML tags using CSS selectors.

Important Notes:

  • CSS is used for styling a website. It makes the website look better and more attractive. You can change the color of paragraphs and other HTML elements using CSS. It reads and applies the styles based on the HTML tags and their structure.
  • The CSS stylesheet must first be linked to the HTML file.
  • When a stylesheet becomes too large, it can be difficult to manage.
  • It is better to use separate CSS files when the stylesheet becomes too loaded.
  • One HTML file can use two or more CSS files.

Keyboard Shortcuts:

  • Alt + Z – turns text wrapping on or off.
  • Shift + Scroll Wheel – moves the screen from left to right and vice versa.

Overall, the lesson taught how to use CSS selectors to target HTML elements and add styles to different parts of a website.
