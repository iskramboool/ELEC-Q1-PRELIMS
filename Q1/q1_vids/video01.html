Introduction to HTML and CSS

The lesson introduced the basic steps in creating a website using HTML and CSS. Different coding platforms were
discussed, with VS Code being the most recommended because it is easy to use and has useful features.

Important Notes:

  • VS Code – a recommended platform for coding.
  • index.html – the common name for the main page of a website.
  • HTML – used to create the basic structure of a website.
  • html:5 – creates a basic HTML template.
  • CSS – used to design and make the website look better.
  • Files and folders – should be organized properly.
  • Viewport tag – helps the website fit different devices like computers, tablets, and phones.

Overall, the lesson taught the basic use of HTML and CSS and how to start creating a simple website.
